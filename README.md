# 🔍 틀린그림 찾기

**바로 하기 → <https://grapi.github.io/diffpic/>**
(태블릿·폰에서 열고 메뉴 → `앱 설치` 를 누르면 아이콘이 생기고 인터넷 없이도 됩니다)

두 그림에서 **다른 곳 5군데**를 찾는 게임. 그림 15개를 모두 깨면 완주하고, 점수를 기록으로 남깁니다.
외부 라이브러리 없이 Node 내장 모듈과 바닐라 JS만 씁니다.

## 실행

```bash
npm start
```

```
  이 컴퓨터    http://localhost:3001
  태블릿·폰    http://192.168.0.10:3001      ← 주소는 컴퓨터마다 다릅니다
```

포트 변경은 `PORT=8080 npm start`. 태블릿·폰은 같은 와이파이에서 위 주소로 들어가면 되고,
메뉴 → `홈 화면에 추가 / 앱 설치` 를 하면 아이콘이 생기고 인터넷 없이도 됩니다.
소리가 안 나면 아이폰·아이패드의 무음 스위치를 확인하세요. 첫 소리는 화면을 한 번 누른 뒤에 납니다(브라우저 정책).

## 규칙

| | |
|---|---|
| 시작 | 함께할 캐릭터를 고르고 이름을 적습니다. 비워 두면 캐릭터의 이름을 씁니다. 모습과 표정만 다르고 규칙은 같습니다 |
| 틀린 곳 | 판마다 정확히 5개. 왼쪽·오른쪽 어느 그림을 눌러도 됩니다 |
| 찾으면 | 양쪽 그림에 색연필 동그라미 + 딩동 + 점수 |
| 아무 데나 누르면 | ✕ 표시 + 삐 소리 + 생명 ❤️ −1 + 연속 끊김 (이미 찾은 곳을 다시 누르는 건 괜찮습니다) |
| 생명 | 처음 5개, 최대 10개. 다 찾으면 +1, 퍼팩트면 +2. 남은 생명을 들고 다음 판으로 갑니다 |
| 끝 | 그림 15개를 모두 깨면 완주, 그 전에 생명이 0이 되면 게임 오버 |
| 기록 | 끝나면 시작할 때 정한 이름으로 점수를 남깁니다. 이 기기에 상위 10개가 저장됩니다 |

### 점수

| | |
|---|---|
| 찾을 때마다 | 100점 |
| 연속 보너스 | 2연속 +50, 3연속 +100 … 한 번에 최대 +500. 틀리기 전까지 다음 판으로도 이어집니다 |
| 퍼팩트 | 판 끝에 +1,000점 |

- 빠르게 두 번 누른 오답이 생명 두 개를 깎지 않도록, 오답 직후 0.4초는 오답을 다시 세지 않습니다.
- 찾는 곳을 손가락으로 눌러도 맞도록 판정 범위는 물체보다 조금 넉넉합니다.
- `다시 섞기` 는 같은 그림에서 틀린 곳만 새로 고릅니다. 이 판에서 얻은 점수와 연속은 사라지고 틀린 기록은 남으므로, 점수를 쌓거나 퍼팩트를 노리는 데 쓸 수 없습니다.
- 장면 순서는 게임마다 섞이고, 같은 장면이 다시 나와도 틀린 곳 5개는 매번 새로 고릅니다.

## 그림은 어떻게 만들어지나

굵은 외곽선·단색 면·볼터치의 플랫 일러스트를 SVG 코드로 직접 그립니다 (이미지 파일 없음).
그림은 세로로 조금 긴 600×800(3:4)이라, 태블릿을 가로로 들면 두 그림이 좌우로 화면을 꽉 채웁니다.
세로로 들거나 폰에서도 두 그림은 항상 좌우로 놓입니다.

장면은 15개입니다: 거실 파티, 공원 소풍, 부엌 요리, 교실 수업, 바닷가, 놀이터, 밤 캠핑, 눈 오는 마을, 바닷속, 우주 탐험, 농장, 빵집, 놀이공원, 아이 방, 동물원.
파일은 `public/lib/scenes/` 에 하나씩 있고, 장면마다 바뀔 수 있는 곳이 17~21곳 있습니다.

1. **장면** — 장면 파일의 `draw(v)` 가 그림 전체를 그립니다. 사람·고양이·강아지·나무·해 같은
   공용 부품은 `public/lib/art.js` 에 있습니다.
2. **틀린 곳** — 장면 파일의 `diffs` 가 바뀔 수 있는 곳 목록(이름과 판정 원)입니다. `draw` 안의
   `pick(v, 'id', 원래, 바뀐것)` 이 오른쪽 그림에서만 바뀐 모습을 그립니다. `public/lib/diff.js` 가
   판정 원이 겹치지 않게 5곳을 무작위로 고릅니다.
3. **동그라미** (`public/lib/crayon.js`) — 한 바퀴를 조금 넘게 도는 흔들리는 타원에 SVG 필터로 크레용 질감을 입혀 그려지는 모습으로 보여줍니다.

장면을 늘리려면 `public/lib/scenes/` 에 같은 모양의 파일을 만들고 `diff.js` 의 `SCENES` 와 `sw.js` 의 `ASSETS` 에 추가하면 됩니다. 장면 수가 곧 완주까지의 판 수가 됩니다.
화면 아래에는 장면 이름과 문제 번호(시드)가 나옵니다. 같은 장면·같은 번호면 언제나 같은 문제입니다.

## 테스트

```bash
npm test
```

장면마다 — 후보 하나하나가 실제로 그림을 바꾸는지, 판정 원이 그림 안에 있는지 — 와,
장면 15개 × 시드 300개에 대해 — 틀린 곳이 정확히 5개인지, 판정 범위끼리 겹치지 않는지,
고른 5곳 말고는 두 그림이 완전히 같은지 — 그리고 생명 규칙(−1, 0이면 끝, 다 찾으면 +1, 퍼팩트 +2, 최대 10),
점수 규칙(연속 보너스, 퍼팩트 보너스, 다시 섞기), 기록 순위를 검사합니다.

## 배포

`.github/workflows/pages.yml` 이 `main` 에 올라올 때마다 테스트를 돌리고, 통과하면 `public/` 을 GitHub Pages 로 내보냅니다.
파일을 고친 뒤에는 `public/sw.js` 의 `CACHE` 숫자를 올려야 설치된 태블릿이 새 버전을 받습니다.
