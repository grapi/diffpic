# 🔍 틀린그림 찾기

**바로 하기 → <https://grapi.github.io/diffpic/>**
(태블릿·폰에서 열고 메뉴 → `앱 설치` 를 누르면 아이콘이 생기고 인터넷 없이도 됩니다)

두 그림에서 **다른 곳 5군데**를 찾는 게임. 그림은 코드가 매번 새로 그리므로 판이 끝없이 나옵니다.
외부 라이브러리 없이 Node 내장 모듈과 바닐라 JS만 씁니다.

## 실행

```bash
npm start
```

```
  이 컴퓨터    http://localhost:3001
  태블릿·폰    http://192.168.0.10:3001      ← 주소는 컴퓨터마다 다릅니다
```

포트 변경은 `PORT=8080 npm start`. 태블릿·폰은 같은 와이파이에서 위 주소로 들어가면 되고,
메뉴 → `홈 화면에 추가 / 앱 설치` 를 하면 아이콘이 생기고 인터넷 없이도 됩니다.
소리가 안 나면 아이폰·아이패드의 무음 스위치를 확인하세요. 첫 소리는 화면을 한 번 누른 뒤에 납니다(브라우저 정책).

## 규칙

| | |
|---|---|
| 틀린 곳 | 판마다 정확히 5개. 왼쪽·오른쪽 어느 그림을 눌러도 됩니다 |
| 찾으면 | 양쪽 그림에 색연필 동그라미 + 딩동 |
| 아무 데나 누르면 | ✕ 표시 + 삐 소리 + 생명 ❤️ −1 (이미 찾은 곳을 다시 누르는 건 괜찮습니다) |
| 생명 | 처음 5개, 최대 10개. 남은 생명을 들고 다음 판으로 갑니다 |
| 퍼팩트 | 한 번도 안 틀리고 5개를 다 찾으면 생명 +1 |
| 게임 오버 | 생명이 0이 되면 1판·생명 5개로 다시 시작 |

- 빠르게 두 번 누른 오답이 생명 두 개를 깎지 않도록, 오답 직후 0.4초는 오답을 다시 세지 않습니다.
- 찾는 곳을 손가락으로 눌러도 맞도록 판정 범위는 물체보다 조금 넉넉합니다.
- `새 그림` 은 같은 판에서 그림만 바꿉니다. 이 판에서 틀린 기록은 남으므로 퍼팩트를 노리고 바꿀 수는 없습니다.
- 판이 올라갈수록 물체가 많아지고(10 → 16개) 작아집니다.

## 그림은 어떻게 만들어지나

1. **장면** (`public/lib/scene.js`) — 시드로 하늘·언덕 색을 고르고 해, 구름·새·풍선(하늘), 집·나무·꽃·고양이·버섯·자동차·나비(땅)를
   서로 겹치지 않게 흩어 놓습니다. 물체 모양은 `public/lib/shapes.js` 에 있습니다.
2. **틀린 곳** (`public/lib/diff.js`) — 물체 5개를 골라 각각 다른 변형을 하나씩 줍니다:
   색 바꾸기 · 없애기 · 크기 바꾸기 · 좌우 뒤집기 · 부분 바꾸기(창문, 사과 개수, 꼬리, 무늬 …) · 하나 더 추가 중 5가지.
   너무 작은 물체나 비슷한 색으로의 변화처럼 눈에 안 띄는 차이는 만들지 않습니다.
3. **동그라미** (`public/lib/crayon.js`) — 한 바퀴를 조금 넘게 도는 흔들리는 타원에 SVG 필터로 크레용 질감을 입혀 그려지는 모습으로 보여줍니다.

화면 아래 `그림 번호` 는 그 그림의 시드입니다. 같은 번호·같은 판이면 언제나 같은 그림이 나옵니다.

## 테스트

```bash
npm test
```

시드 300개 × 판 4종류에 대해 — 틀린 곳이 정확히 5개이고 종류가 모두 다른지, 판정 범위끼리 겹치지 않는지,
틀린 곳 말고는 두 그림이 완전히 같은지 — 와 생명 규칙(−1, 0이면 끝, 퍼팩트 +1, 최대 10)을 검사합니다.

## 배포

`.github/workflows/pages.yml` 이 `main` 에 올라올 때마다 테스트를 돌리고, 통과하면 `public/` 을 GitHub Pages 로 내보냅니다.
파일을 고친 뒤에는 `public/sw.js` 의 `CACHE` 숫자를 올려야 설치된 태블릿이 새 버전을 받습니다.
